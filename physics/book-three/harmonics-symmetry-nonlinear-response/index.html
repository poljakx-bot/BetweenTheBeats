Path III · Theme 9

Harmonics, Symmetry and Nonlinear Response

A nonlinear receiver does not merely respond more strongly. It can generate new frequencies whose pattern exposes the symmetry of the underlying dynamics.

Published essay

Why harmonics matter

A harmonic spectrum is a structural constraint, not decorative complexity.

Standard nonlinear optics already links harmonic order to material symmetry. A Titraj model must therefore predict that structure from its proposed receiver geometry rather than merely reproduce the word “nonlinear.”

Intuition

A pure note can make overtones inside matter

Drive a nonlinear receiver with one frequency \(\omega\). The output need not contain only \(\omega\). It can contain \(2\omega\), \(3\omega\) and higher harmonics.

That is already a clue that the receiver is doing more than passively intercepting energy. Its internal response reshapes the field.

The harmonic spectrum is a fingerprint of the receiver’s symmetry and nonlinearity.

Symmetry decides what is allowed

If the response is unchanged under inversion in the appropriate way, some harmonic orders cancel. Break that symmetry and previously forbidden components can appear.

Path III therefore gains a powerful test. A proposed many-electron geometry must predict which harmonics survive, how they are polarised, how strong they are and what changes when the material symmetry is deliberately altered.

The Argument

1. Start from the standard nonlinear expansion

For an electric response written as a polarisation, one may expand

\[\mathbf P=\varepsilon_0\left(\chi^{(1)}\mathbf E+\chi^{(2)}\mathbf E^2+\chi^{(3)}\mathbf E^3+\cdots\right).\]

The first term gives linear response. Higher powers generate new frequency components.

2. A quadratic response generates a second harmonic

Let

\[E(t)=E_0\cos\omega t.\]

Then

\[E^2(t)=E_0^2\cos^2\omega t=\frac{E_0^2}{2}\left(1+\cos2\omega t\right).\]

A quadratic response therefore contains a DC component and a term at \(2\omega\).

3. A cubic response generates a third harmonic

Likewise,

\[\cos^3\omega t=\frac{3}{4}\cos\omega t+\frac{1}{4}\cos3\omega t.\]

A cubic response can therefore reinforce the fundamental and generate \(3\omega\).

4. Inversion symmetry constrains even orders

In an inversion-symmetric medium, the electric-dipole response satisfies

\[\mathbf P(-\mathbf E)=-\mathbf P(\mathbf E).\]

An even-power term would violate that relation, so electric-dipole contributions such as \(\chi^{(2)}\) vanish in the ideal bulk centrosymmetric case.

Break inversion symmetry—at a surface, interface, oriented structure or non-centrosymmetric crystal—and even-order response can appear.

5. Half-cycle antisymmetry gives the same lesson in time

If a current or dipole response obeys

\[J(t+T/2)=-J(t),\]

its Fourier series contains only odd harmonics. Even harmonics require that this half-cycle antisymmetry be broken.

6. The Titraj extension

Path III interprets these selection rules as constraints on a proposed physical receiver geometry. If the organised many-electron motion has a symmetry, its harmonic spectrum should inherit that symmetry.

\[\text{mode symmetry}\rightarrow\text{Fourier selection rules}.\]

This is where the model becomes testable. It must map geometry to spectrum before seeing the answer.

7. The local-c path is not needed for the symmetry test

A many-electron mode can have a well-defined symmetry whether or not any electron locally moves at \(c\). Therefore harmonic selection rules can test the organised-receiver hypothesis independently of the strongest trajectory conjecture.

If H3 is retained, it must add a sharper prediction: the constrained path family and its half-cycle geometry should generate a calculable Fourier spectrum.

Deep Notes

This section begins with a single sinusoidal drive and derives why nonlinear material response creates harmonics. It then shows how symmetry removes some orders and states exactly what a Titraj geometry would have to predict.

1. Linear response cannot create new frequencies by itself

Suppose a receiver is driven by

\[E(t)=E_0\cos\omega t.\]

If the response is strictly linear,

\[P^{(1)}(t)=\varepsilon_0\chi^{(1)}E_0\cos\omega t.\]

The output oscillates at the same frequency \(\omega\). Amplitude and phase can change, but no harmonic at \(2\omega\) or \(3\omega\) appears from linearity alone.

2. Nonlinearity mixes the drive with itself

Include higher powers:

\[P(t)=\varepsilon_0\left(\chi^{(1)}E+\chi^{(2)}E^2+\chi^{(3)}E^3+\cdots\right).\]

Using the identities

\[\cos^2\omega t=\frac{1+\cos2\omega t}{2},\]
\[\cos^3\omega t=\frac{3\cos\omega t+\cos3\omega t}{4},\]

shows directly that the nonlinear response contains new Fourier components.

3. Harmonic order carries symmetry information

A centrosymmetric electric-dipole medium satisfies

\[P(-E)=-P(E).\]

An expansion consistent with this relation contains only odd powers of \(E\). Therefore the lowest bulk electric-dipole nonlinear term is cubic rather than quadratic.

This does not mean even harmonics can never be observed. Surfaces, interfaces, magnetic-dipole terms, electric-quadrupole terms and broken symmetry can provide additional channels. The selection rule tells us what ideal symmetry would suppress.

4. Time-domain symmetry gives the same selection rule

Let the response be periodic with period \(T\). If

\[J(t+T/2)=-J(t),\]

then translating by half a period flips the sign. For a Fourier component \(e^{in\omega t}\), the same translation contributes a factor \((-1)^n\). Only odd \(n\) are compatible with the required sign change.

Thus half-cycle antisymmetry implies odd harmonics.

5. Deliberate symmetry breaking is an experimental lever

If a receiver geometry is changed in a controlled way so that inversion or half-cycle symmetry is broken, an organised-mode model should predict which new harmonic components appear and how their polarisation changes.

This is stronger than fitting a spectrum after measurement because the material modification is known in advance.

6. What Titraj must add

The standard susceptibility expansion already predicts nonlinear spectra. Titraj earns relevance only if its proposed charge geometry explains why the effective nonlinear coefficients and selection rules take the values they do for the material being studied.

The required chain is

\[\text{material structure}\rightarrow\text{allowed charge geometry}\rightarrow\text{time-dependent current or dipole}\rightarrow\text{Fourier spectrum}.\]

7. If the local-c hypothesis is retained

A constrained local-c path would define \(\mathbf r(t)\) or \(\mathbf J(t)\) over the cycle. Its Fourier decomposition would then predict harmonic orders and relative amplitudes.

The local-c hypothesis is useful only if that calculation produces risky predictions. Merely observing odd harmonics and declaring them compatible with a symmetric path is not enough.

8. Open obligations

A quantitative Titraj harmonic model should predict:

  • which harmonic orders are allowed or suppressed;
  • relative harmonic strengths;
  • polarisation of each harmonic;
  • angular emission pattern;
  • dependence on crystal, molecular or device orientation;
  • changes under deliberate symmetry breaking;
  • the drive-intensity regime where perturbation theory fails.

9. What this theme establishes

\[\boxed{\text{harmonic spectrum}\rightarrow\text{constraint on receiver symmetry and dynamics}.}\]

The result is useful even before a complete Titraj trajectory exists: harmonics tell us what any proposed receiver geometry is allowed to look like.
